# Dashboard Wireframes

A simple HTML wireframe mockups for Agency, Brand, and Creator dashboards.

## 🎨 Live Demo

View the wireframes: **[Live Demo](https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/)**

## 📋 Overview

This project contains 40+ wireframe pages designed to help visualize the structure and layout of three different dashboard types:

- **Agency Dashboard** (13 pages) - Manage multiple brands and oversee campaigns
- **Brand Dashboard** (14 pages) - Create and manage influencer campaigns
- **Creator Dashboard** (13 pages) - Find campaigns and manage collaborations
- **Shared Pages** (2 pages) - Common marketplace and campaign views

## 🚀 Getting Started

Simply open `index.html` in your browser to navigate through all wireframes.

